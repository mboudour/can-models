## Requested Study 1 package

| Material | Why the replication requires it |
|---|---|
| De-identified cleaned analytic file | Required to reproduce the reported 15-country Study 1 network and subgroup/country comparisons. |
| Original variable names, labels, and response values | Required to map the paper’s nodes and retain ordinal/categorical treatment. |
| Reverse-coding and category-collapse rules | Required to avoid undocumented recoding. |
| Participant-exclusion flags and final analytic-sample logic | Required to reproduce the reported *N* = 8,046. |
| Country codes and country-name key | Required for country networks, NCTs, clustering, and NetworkTree. |
| Political-orientation coding and grouping rule | Required for the left/right PA network branch. |
| PA, nativism, threat, conspiracy, and demographic variable map | Required to reconstruct the exact paper model rather than an approximation. |
| Questionnaire language versions and translations | Required for a cross-country measurement and interpretation audit. |
| Any author-approved analysis script or supplement | Required to resolve implementation details not fully specified in the article text. |

## Access alternatives

A secure remote analysis environment, an approved institutional data-access agreement, or author-run execution of a provided replication script are valid alternatives if direct data transfer is not permissible. The repository must not add Study 1 data or derived row-level data to public version control without explicit written authorization.
